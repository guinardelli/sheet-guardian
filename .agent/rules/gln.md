# Ferramentas, Skills e MCP's

- Sempre que possível use as ferramentas disponíveis, skill's e MCP's. Isso irá lhe ajudar a desenvolver o código da melhor forma possível

- É sempre importante usar os artefatos para deixar claro para os agentes qual é o plano de implementação.

- Quando alguma tarefa for muito repetitiva ou você perceber que necessita executá-la com frequência, avalie se a criação de uma Skill seria útil. Se for util, pode criar usando o @SKILL.md da pasta creating-skills para criar a skill.
